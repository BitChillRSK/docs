# Audit status

No manual audit of this protocol version is published.

An audit is planned. The protocol is not deployed before that audit. These pages do not link to an audit report for this version.

## Earlier reports

The 2025 Ivan Fitro reports cover earlier contract versions. They are not a manual audit of this version. This page does not say that this version passed those reviews. This page does not say that their findings were addressed in this version.

## Before deployment

The deployment script can deploy the manager, the registry, and the seven handlers on Rootstock mainnet. That deployment waits for the planned audit. Until then, the address page has no protocol contract address.

## Report a vulnerability

When you have a security report, send it in private. Use a direct message to [@BitChillApp](https://x.com/BitChillApp).

For a bug that is not a vulnerability, open an issue on [dca-contracts](https://github.com/BitChillRSK/dca-contracts/issues).
